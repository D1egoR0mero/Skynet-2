Requires Node.js 20+.

All PM2.1 regression and PM2.2 keyword tests:
  npm test

PM2.1 only:
  node --test test/pm21-*.test.js

PM2.2 only:
  node --test test/pm22-*.test.js

Provider requests use fixtures. Server integration tests need permission to
listen on localhost; they use temporary project copies and do not change your
listings cache. UI interaction tests use a small DOM harness, not a real browser.
AI prompts/scope: docs/ai/PM2.2-ai-usage.md
